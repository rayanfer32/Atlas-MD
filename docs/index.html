Architecture Highlights

Engineered with resilient persistence & failover.

Unlike single-instance bots that crash under heavy load or lose message context, Atlas-MD implements a multi-layer architectural design:

1

Dual MongoDB Clustered Connection

Distributes user and group collections across DB1 and DB2 connections to eliminate database bottlenecks.

2

TTL-Expiring In-Memory Message Vault

Captures every incoming message into a bounded queue (default 500 msgs/chat) with automatic background pruning.

3

Automatic Reconnection Watchdog

Periodically verifies WebSocket health, auto-restarts stale connections, and reports status via heartbeat hooks.
